# 桌面宠物 精灵图规范（供 AI 绘图 & 手工替换参考）

> 目标：生成一张 **可被程序直接读取** 的 `spritesheet.png`，放入 `pet/assets/sprites/` 后，程序即可自动识别并播放对应动画。  
> 程序兼容 **Codex hatch-pet 标准**：1536×1872、8 列 × 9 行、每格 192×208、PNG 透明背景。

---

## 1. 硬性规格（必须完全一致）

| 项目 | 数值 | 说明 |
|------|------|------|
| 文件名 | `spritesheet.png` | 固定，不可改 |
| 画布尺寸 | **1536 × 1872 px** | 8 列 × 192 = 1532？不对 → 8×192=1536；9×208=1872 |
| 网格 | **8 列 × 9 行** | 列 = 帧，行 = 状态 |
| 单格尺寸 | **192 × 208 px** | `cell_w × cell_h` |
| 色彩模式 | **RGBA (32-bit)** | 必须含 Alpha 通道 |
| 背景 | **完全透明 (Alpha=0)** | 无灰底、无网格线、无水印 |
| 未用格 | **完全透明** | 超过该状态帧数的格子留空 |

> ⚠️ 程序在 `spritesheet.py` 中按 `cfg.cell_w=192, cell_h=208, cols=8, rows=9` 硬切图；**任何尺寸偏差都会导致错位或读取失败**。

---

## 2. 行号 ↔ 状态映射（固定，不可随意改动）

程序在 `config.py -> AtlasConfig.row_map` 中定义，`states.py -> PetState` 枚举对应：

| 行号 (row) | 状态名 | 枚举值 | 默认帧数 | 说明 |
|-----------|--------|--------|----------|------|
| 0 | `idle` | `IDLE` | 6 | 待机：眨眼、环顾 |
| 1 | `happy` | `HAPPY` | 5 | 开心：原地跳跃、眯眼笑 |
| 2 | `eating` | `EATING` | 5 | 进食：张嘴咀嚼、有食物图标 |
| 3 | `sleeping` | `SLEEPING` | 4 | 睡眠：闭眼、Zzz、微微起伏 |
| 4 | `sad` | `SAD` | 4 | 难过：垂头、流泪 |
| 5 | `busy` | `BUSY` | 5 | 忙碌：敲键盘/看屏幕、冒汗 |
| 6 | `waving` | `WAVING` | 4 | 挥手：抬手打招呼 |
| 7 | `drag` | `DRAG` | 3 | 被拖拽：身体扁平、速度线 |
| 8 | `speaking` | `SPEAKING` | 4 | 说话/气泡：张嘴 |

> **如需改行号**，必须同步修改 `config.json` 的 `atlas.row_map` 与 `states.py` 的枚举顺序，**强烈建议保持默认**。

## 3. 每行帧数与播放时长（来自 `states.py -> STATE_TIMING`）

| 状态 | 帧数 | 每帧时长 | 循环？ |
|------|------|----------|--------|
| idle | 6 | 280, 110, 110, 140, 140, 320 ms | ✅ 是 |
| happy | 5 | 140, 140, 140, 140, 280 ms | ❌ 否（播完回 idle） |
| eating | 5 | 150, 150, 150, 150, 260 ms | ❌ 否 |
| sleeping | 4 | 520, 520, 520, 520 ms | ✅ 是 |
| sad | 4 | 180, 180, 180, 300 ms | ❌ 否 |
| busy | 5 | 120, 120, 120, 120, 220 ms | ❌ 否 |
| drag | 3 | 100, 100, 200 ms | ❌ 否（拖拽期间持续） |
| waving | 4 | 140, 140, 140, 280 ms | ❌ 否 |
| speaking | 4 | 150, 150, 150, 280 ms | ❌ 否 |

**关键点**：
- 每行**前 N 格**对应 N 个帧，**多余格子必须留透明**
- `idle` 和 `sleeping` 是循环动画（`loop=True`），其余播放一次后自动回 `idle`
- 最后一帧通常是“定格/收尾帧”，不要画成中间过渡帧

## 4. 程序如何读取与渲染（关键实现细节）

### 4.1 切图逻辑 (`spritesheet.py`)
```python
# 伪代码
for state in PetState:
    row = row_map_reverse[state]  # 反查行号
    count = min(len(STATE_TIMING[state]), cfg.cols)  # 取帧数与 8 列的较小值
    for col in range(count):
        x, y = col * 192, row * 208
        cell = sheet.subsurface((x, y, 192, 208))
```

### 4.2 绘制位置 (`renderer.py -> _draw_image`)
```python
# 图片底部对齐窗口底部，留 26px 边距，水平居中
x = window_w // 2
y = window_h - 26 - img.height() // 2
```
> **设计建议**：把角色**脚部/身体底部**放在单格**下方 10~20px** 处，头部向上延伸；不要画满整格，否则会贴着窗口边缘。

### 4.3 点击判定 (`renderer.py -> is_over_body`)
- 以窗口中心 `(w*0.5, h*0.55)` 为椭圆中心
- 半径：`rx = w*0.34 ≈ 82px`, `ry = h*0.27 ≈ 73px`
- **角色主体像素应落在该椭圆内**，否则点击不触发交互

### 4.4 兜底渲染 (`renderer.py -> _draw_vector`)
无图时程序用代码画椭圆、眼睛、嘴巴、手臂、红晕、汗滴、Zzz、食物图标。**有图时完全不走这套逻辑**，所以**图里必须包含所有表现细节**（眨眼、张嘴、手臂、汗、泪、Zzz 等）。

## 5. 视觉设计规范（给 AI / 绘师的 Prompt 要点）

### 5.1 整体风格
- 统一色调、统一线条粗细（建议 2~4px 描边）、统一光源方向
- **同一行所有帧必须是同一角色、同一比例、同一视角**
- 角色在格子内**垂直居中偏下**，水平居中

### 5.2 各状态关键表现（必须画在对应帧里）

| 状态 | 必须包含的视觉要素 |
|------|-------------------|
| **idle (6帧)** | 帧0~1: 睁眼；帧1~2: 眨眼（闭眼/半闭眼）；帧3~5: 环顾/微动 |
| **happy (5帧)** | 开心跳跃：身体上下位移、眯眼笑、脸红、可选手臂上扬 |
| **eating (5帧)** | 张嘴、咀嚼动作、嘴边/手里有食物图标（苹果/蛋糕等）、最后一帧咽下 |
| **sleeping (4帧)** | 闭眼（弧线眼）、身体微微起伏（呼吸）、头旁 Zzz 气泡渐大渐远 |
| **sad (4帧)** | 垂头、眼睛向下/流泪、嘴巴下弯、可选泪滴落下 |
| **busy (5帧)** | 双手敲键盘姿势、侧身看屏幕、额头/旁边冒汗滴、身体微前倾 |
| **waving (4帧)** | 一只手抬起挥动、身体微侧、脸朝前、眯眼笑 |
| **drag (3帧)** | 身体压扁（ry * 0.78）、四肢摊开、身体下方/周围有速度线/运动模糊 |
| **speaking (4帧)** | 嘴巴张合节奏（配合气泡文字）、可选手势、表情自然 |

### 5.3 透明度与边缘
- **格子边缘 8~12px 必须全透明**，防止切图时边缘溢出
- 不要在格子外画阴影、光晕、速度线——**全部要在 192×208 内**
- 描边颜色建议深棕 `#3b2b20` 或同色系深色，线宽 2~3px

### 5.4 色板建议（与兜底渲染 `BODY_COLORS` 对应）
| 状态 | 主体色 | 备注 |
|------|--------|------|
| idle/happy/waving/speaking | `#ffd28a` | 暖黄/橙黄 |
| eating | `#ffd9a0` | 稍亮 |
| sleeping | `#c9b6e8` | 淡紫 |
| sad | `#a8bfe0` | 淡蓝 |
| busy | `#ffcf7d` | 橙黄 |
| drag | `#e8c37a` | 深黄 |

> 建议以此色板为基础，保持角色主色调一致；服饰/配饰可加少量对比色。

## 6. 生成与替换流程

### 6.1 使用 AI 生成（推荐）
1. 按上述规格写 Prompt，逐行/逐状态生成 **条带图**（单行 8 帧横排）
2. 用图像编辑器拼成 1536×1872 大图，或直接让 AI 输出整张
3. 检查：尺寸、透明背景、每行帧数、角色一致性
4. 覆盖 `pet/assets/sprites/spritesheet.png`

### 6.2 使用占位生成器（开发/测试用）
```bash
python tools/make_placeholder_sheet.py
```
- 程序会按 `STATE_TIMING` 帧数、代码绘制矢量占位图
- 输出：`pet/assets/sprites/spritesheet.png`（1536×1872）
- **仅作占位**，视风格简陋，**发布前必须替换为美术图**

### 6.3 验证方法
```bash
python main.py
```
- 观察是否正常播放 9 种状态动画
- 右键菜单测试：投喂→eating、互动→happy、睡眠→sleeping、挥手→waving
- 拖拽窗口→drag 状态
- 发送测试消息→speaking + busy

## 7. 常见坑 & Checklist

| 问题 | 原因 | 解决 |
|------|------|------|
| 动画错位/撕裂 | 画布非 1536×1872 或单格非 192×208 | 严格按规格导出 |
| 某状态不播放 | 该行帧数 < `STATE_TIMING` 定义 | 补足帧数，或改 `STATE_TIMING` |
| 角色偏上/偏下 | 绘制位置计算基于图片底部 | 角色脚部靠近格子底部 10~20px |
| 点击无反应 | 主体像素超出椭圆判定区 | 缩小角色或调整判定参数 |
| 背景有灰边 | 导出时未勾选透明/Alpha 预乘 | 导出 PNG 时确保 Alpha=0 背景 |
| 拖拽时变形 | drag 状态 ry*0.78 压扁 | 原图画扁平姿态，不要靠程序压缩 |
| 帧率过快/过慢 | `STATE_TIMING` 毫秒数不符预期 | 调整 `states.py` 或重画帧数 |

✅ **上线前自检清单**
- [ ] 文件名 `spritesheet.png`、放在 `pet/assets/sprites/`
- [ ] 1536×1872、PNG、透明背景
- [ ] 9 行全有内容、多余格透明
- [ ] 每行帧数 ≥ `STATE_TIMING` 定义值
- [ ] 角色主体在椭圆判定区内
- [ ] 无外溢阴影/光晕/水印
- [ ] `python main.py` 可完整跑通 9 状态

## 8. 进阶：自定义行映射 / 增加状态

如需新增状态（如 `running`、`jumping`）：
1. `states.py` 增加 `PetState` 枚举值
2. `STATE_TIMING` 增加帧时长列表
3. `config.py` `AtlasConfig.row_map` 增加行号映射
4. `renderer.py` `BODY_COLORS` 增加颜色
5. 精灵图增加对应行（需扩展 `rows` 或复用空行）
6. `spritesheet.py` 会自动读取新映射

> 当前 `rows=9` 已满，**新增状态需修改 `AtlasConfig.rows` 并重新生成更大图集**，建议评估后再做。
