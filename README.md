# 桌面宠物 (Desktop Pet)

一个基于 Python + Tkinter 实现的桌面宠物程序，兼容 Codex hatch-pet 的精灵图规范。

## ✨ 功能特性
- **沉浸式无边框窗口**：置顶显示、背景透明、支持点击穿透（不阻挡下层鼠标操作）
- **多屏幕适配**：智能识别当前显示器，键盘移动和随机移动永不越界，也不会被任务栏遮挡
- **系统托盘**：提供托盘图标，支持隐藏/显示宠物、提至最前、快捷互动、打开面板和退出
- **互动系统**：点击抚摸、双击挥手、拖拽移动
- **投喂系统**：6 种虚拟食物（苹果、蛋糕、鱼干等），以及独特的 **“本地文件投喂”** 玩法
- **三维属性**：饥饿/心情/精力，支持离线时间流逝计算，极度饥饿时会触发特殊抱怨
- **状态机动画**：13 种状态（待机、开心、进食、睡眠、移动、拖拽等）
- **高度可定制**：所有属性衰减速度、状态阈值、UI 行为参数均可通过控制面板实时调节并保存
- **数据持久化**：自动保存/加载宠物状态到 `data/pet_state.json`
- **消息提醒框架**：支持模拟器与 JSON 文件监听，方便外部程序接入

## 📦 安装与打包

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 启动程序
```bash
python main.py
```

#### 启动参数：
- `--no-click-through`: 禁用点击穿透（方便调试）
- `--config <path>`: 指定额外的配置文件路径

### 程序打包
1. 在项目根目录的终端中安装`pyinstaller`库：
```bash
pip install pyinstaller
```
2. 在项目根目录执行以下两条命令之一：
```bash
# 单文件打包
pyinstaller --onefile --windowed --name "DesktopPet" --additional-hooks-dir=. --add-data "pet/assets;pet/assets" main.py 

# 依赖文件单独放在一个文件夹
pyinstaller --windowed --name "DesktopPet" --additional-hooks-dir=. --add-data "pet/assets;pet/assets" main.py 

```

## 🎮 操作说明

| 操作 | 效果 |
|-----|------|
| 左键点击（未拖拽） | 选中 / 取消选中宠物，并抚摸互动 |
| 拖拽鼠标 | 移动宠物窗口（自动播放拖拽动画） |
| 右键菜单 | 投喂、互动、挥手、睡眠/唤醒…… |
| 方向键 | 选中时移动宠物 |
| ESC | 退出程序 |
|系统托盘|隐藏/显示宠物、提至最前、直接投喂或退出|

## 🍽️ 投喂玩法

### 虚拟食物
- 方法一：右键菜单 -> 投喂，直接选择食物
- 方法二：控制面板 -> 快捷操作 -> 选择食物并点击投喂

### 本地文件投喂 (⚠️危险动作)
- 方法一：将文件拖入宠物身体可直接投喂
- 方法二：右键菜单 -> 投喂 -> 本地文件投喂
> **⚠️警告：** 方法一投喂后，源文件将被永久删除，不会进入回收站！
> 
> **首次启动**会弹出安全提示；若使用菜单投喂，会有二次确认框。

计分规则：基础值 1，根据扩展名（如 .py\*10, .txt\*5）和文件名关键词（如包含“水果”、“gift”）获得倍率加成。

## ⚙️ 控制面板 (UI)
右键宠物选择“控制面板”打开：
- **状态监控**：实时查看饱食度、心情、精力
- **快捷操作**：快速互动、睡眠、喂食
- **参数设置**：自定义属性衰减速度、饥饿/困倦/极度饥饿阈值、随机行为概率等
- **高级选项**：切换置顶、点击穿透、消息提示音；自定义图集行列数；保存与重置配置

## 🖼️ 精灵图规范
如需替换自定义贴图，请按以下规范制作，并放在`pet/assets/sprites/`目录下。

### 1.情绪图集：`spritesheet.png`
- **画布尺寸**：1536 × 1872 像素（8 列 × 9 行，每格 192 × 208）
- **背景**：透明
- **行号对应状态**（可在 config.json 中修改 atlas.row_map）：

| 行号 | 状态名 | 说明 |
|------|--------|-----|
| 0 | idle | 待机/眨眼/环顾 |
| 1 | happy | 开心/跳跃 |
| 2 | eating | 进食/张嘴 |
| 3 | sleeping | 睡觉/闭眼/Zzz |
| 4 | sad | 难过/流泪 |
| 5 | busy | 忙碌/敲键盘/电脑屏幕 |
| 6 | waving | 挥手/打招呼 |
| 7 | drag | 被拖拽 |
| 8 | speaking | 说话/张嘴 |

每行帧数建议参考 pet/states.py 中的 STATE_TIMING（每状态每帧时长表）

### 2. 移动图集：`move_spritesheet.png`
- **画布尺寸**：768 × 832 像素（4 列 × 4 行，每格 192 × 208）
- **背景**：透明
- **行号对应状态**（可在 config.json 中修改 move_atlas.row_map）：

| 行号 | 状态名 | 说明   |
|------|--------|------|
| 0 | move_up | 向上移动 |
| 1 | move_down | 向下移动 |
| 2 | move_left | 向左移动 |
| 3 | move_right | 向右移动 |

> **注意**：没有图片/图片读取失败时，程序会自动使用内置的矢量图形

## 📂 目录结构
```
MyDesktop/
├── main.py                 # 入口
├── hook-tkinterdnd2.py     # 打包依赖
├── requirements.txt        # 依赖文件
├── pet/                    # 核心包
│   ├── app.py              # 主逻辑、主循环
│   ├── window.py           # 无边框窗口、穿透、多屏限制
│   ├── renderer.py         # 图集与矢量渲染
│   ├── spritesheet.py      # 图集切割
│   ├── states.py           # 状态机与帧定时
│   ├── stats.py            # 属性计算与持久化
│   ├── foods.py            # 食物目录与文件投喂算法
│   ├── notifier.py         # 消息框架 (JSON监听)
│   ├── config.py           # 配置加载与合并
│   ├── gui_panel.py        # 控制面板 (带滚动条)
│   ├── tray.py             # 系统托盘管理
│   └── assets/             # 静态资源
│       ├── icon.png        # 托盘图标（可选，无则自动画圆）
│       └── sprites/        # 精灵图集
├── tools/                  # 工具脚本
│   └── make_placeholder_sheet.py
└── data/                   # 运行时数据（自动生成）
    ├── config.json         # 用户配置
    ├── pet_state.json      # 属性存档
    └── .first_run_done     # 首次使用判断
```
